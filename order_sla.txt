# SLA (Spatial-Language-Action, pi0.5 + 3D 空间对齐) 训练与评估命令

SLA = pi0.5 + 训练期空间对齐损失：PaliGemma 第12层图像 token 经投影器与冻结 OmniVGGT 特征做余弦对齐，
loss = action_loss + 0.5 * align_loss，并在训练时以 0.25 概率去掉 prompt 中的离散 state。
推理与 pi0.5 完全相同，OmniVGGT 只在训练时加载，不会保存进 checkpoint。
代码：lerobot/src/lerobot/policies/sla/（说明见其中 README.md），测试：lerobot/tests/policies/sla/。

数据集（cobot_magic / ALOHA，三相机 head/left/right，14维 state/action）：

root: /home/jchen572/code_file/RBM_lerobot_SLA/lerobotv3_datasets/aloha_cup_selection_right
task: Select the red cup and place it on the black coaster

显存参考（RTX PRO 6000 96GB，bf16 + 梯度检查点）：batch 4 约 41GB（不开 EMA），batch 8 + EMA 约 56GB，
batch 8 约 1.75 s/step。本命令已用 --steps=20 实测通过（从 sla_base 起步 action_loss 0.41→0.24，align_loss≈0.009）。
日志中 action_loss / align_loss 分别记录，loss = action_loss + 0.5 * align_loss。
SLA 默认参数即官方真机配置：
    --policy.align_loss_coeff=0.5 --policy.vla_layers_align=12 --policy.vggt_layers_align=-1
    --policy.state_dropout_prob=0.25 --policy.use_vlm_norm=true --policy.use_vggt_pe=true
    --policy.ignore_img_padding_area=true
--policy.align_loss_coeff=0 即退化为普通 pi0.5 训练（不加载 OmniVGGT）。
显存紧张时可把 OmniVGGT 放到另一张卡：CUDA_VISIBLE_DEVICES=0,1 并加 --policy.align_vggt_device=cuda:1；
或加 --policy.align_feature_batch_size=4 分块提取特征。
不要开启随机裁剪/旋转等几何图像增强：对齐要求图像 token 与 VGGT 特征空间一一对应。
官方配置训练 20000 步、batch 64；单卡 batch 8 时可按需增加 --steps。
EMA 权重保存在 checkpoints/<step>/pretrained_model_ema，官方评估使用 EMA 权重。
